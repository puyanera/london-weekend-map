# London weekend map

A weekly map of kid-friendly London events, built from the Dads in London newsletter.

- `docs/index.html` is the static page, served by GitHub Pages. It uses Leaflet with live OpenStreetMap tiles and reads `docs/data.json`.
- `docs/data.json` is generated by `build_map.py` from `events.json` (weekend newsletter) and `golden.json` (latest Golden Ticket issue).
- `EXTRACTION.md` explains how events are extracted from each email.
- `RUNBOOK.md` is what the cloud routine follows each Wednesday and Thursday.

Weekly update: extract the newsletter into `events.json` and the Golden Ticket into `golden.json`, run `python build_map.py`, commit the changed files and `docs/data.json`.

On the map: blue circles are this weekend, orange larger circles are this week's five picks, purple squares are Golden Ticket events, grey rings are ongoing.

Map data: © OpenStreetMap contributors.
