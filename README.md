# London weekend map

A weekly map of kid-friendly London events, built from the Dads in London newsletter.

- `docs/index.html` is the static page, served by GitHub Pages. It uses Leaflet with live OpenStreetMap tiles and reads `docs/data.json`.
- `docs/data.json` is generated by `build_map.py` from `events.json`.
- `EXTRACTION.md` explains how events are extracted from each newsletter.

Weekly update: extract the newsletter into `events.json`, run `python build_map.py`, commit `events.json` and `docs/data.json`.

Map data: © OpenStreetMap contributors.
